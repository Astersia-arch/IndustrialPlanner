# 【浏览器里的集成工业】版本更新 v1.6.0

大家好！本次更新继续完善产线规划与自动蓝图规划，新增一图流同步，并补充物流动画表现。

自动蓝图规划仍可在设置的实验性功能中开启。

## 其他改动

- 蓝图规划新增历史任务列表，可以切换、暂停、继续和删除任务；刷新页面后可从最近保存的进度继续计算，删除任务不会删除已保存的蓝图。
- 蓝图规划支持下载和导入任务文件，可将生产方案、规划配置及已保存的搜索进度带到其他设备继续计算。
- 蓝图规划窗口新增产线工序图和生成结果预览，方便在计算与保存前后核对生产流程和布局。
- 蓝图规划改为按提案次数设置每轮计算预算，支持暂停后调整预算并继续搜索。
- 蓝图规划支持自动调整 CPU 并行计算数量，并在浏览器支持且实测有收益时使用 GPU 辅助布线；也可关闭自动并行计算。
- 规划进度新增本轮与累计提案数、近期与平均计算速度，以及已验证最优面积的变化曲线，方便观察继续计算带来的改进。
- 优化蓝图规划的布局、物流布线和继续搜索，探索不同长宽比例及输出方式，优先保留通过仿真验证且占地更小的方案。
- 蓝图规划新增逐物品物流设置，可分别选择外部供给的接入方式、固体产物的去向和副产物处理方式；固体产物支持自动比较仓库存货口与协议储存箱方案。
- 蓝图规划新增环境供料配置，可以用树表查看上游需求，选择外部供给或内部生产及其配方；气体散布机的数量与位置由规划器根据布局安排。
- 完善蓝图规划的运行供料与限速检查；因设备按整台放置导致原料不足时，会提示将产线规划中的“设备最低消耗”设为“取整计算”后重新生成任务。
- 自动生成蓝图中的仓库取货口默认开启“无限供应”，便于放置后检查产线运行；实际使用时可按需调整供给条件。
- 降低蓝图规划保存任务进度时的内存开销，改善长时间计算与多任务使用体验。
- 产线规划支持将自然资源设为无限供给，切换后按外部供给计算；取消无限供给时恢复此前填写的有限数量。
- 新增一图流同步，可登录账号同步基地文档、蓝图、模块产线和规划配置的当前内容，并查看账号共享存储用量、手动同步或停用同步；不包含历史记录。
- 新增货物进入设备的动画，让传送带上的货物在成功交接后继续移动进入设备，暂停与回放跳转时同步调整显示。
